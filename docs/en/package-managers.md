# Installing with package managers

[Documentation](index.md) · [Русский](../ru/package-managers.md) · [Releases](releases.md)

Besides GitHub Releases, FormaCAD can be installed with package managers. They download the same installers from GitHub Releases and check SHA-256.

## Commands

| System | Command | State |
|---|---|---|
| Windows | `winget install lovlyDev.FormaCAD` | Package 1.6.1 submitted to the Microsoft catalog ([PR](https://github.com/microsoft/winget-pkgs/pull/470914)); works once accepted |
| macOS | `brew install --cask lovlydev/formacad/formacad` | Own tap `lovlyDev/homebrew-formacad`; works once the tap exists |
| Linux | — | Flathub is planned; for now AppImage, DEB and RPM from the release |

Updates: the app updates itself. `winget upgrade lovlyDev.FormaCAD` or `brew upgrade --cask formacad` also work.

## winget

- The package lives in `packaging/winget/manifests/l/lovlyDev/FormaCAD/<version>/`: version, installer (per-user NSIS, `ProductCode` `Forma`) and English and Russian descriptions. Check with `winget validate --manifest <folder>`.
- Microsoft moderators accept the first version after an automated sandbox check. On the first PR a bot asks for the CLA: reply in the PR with `@microsoft-github-policy-service agree`.
- New versions are submitted by the `package-managers` job of the Release workflow: `wingetcreate update lovlyDev.FormaCAD --version <X.Y.Z> --urls <EXE> --submit`. It needs the `WINGET_TOKEN` secret: a classic GitHub token with `public_repo`. Without the secret the step is skipped with a warning.

## Homebrew

- The app cannot enter the main Homebrew catalog (`homebrew/cask`) yet: that needs a signed, notarized app and a well-known repository. So FormaCAD uses its own tap, `lovlyDev/homebrew-formacad`.
- The cask `Casks/formacad.rb` is generated by `node scripts/homebrew-cask.mjs <version> <SHA256SUMS>`; the 1.6.1 copy is in `packaging/homebrew/`. One cask covers Apple Silicon and Intel with the release DMGs.
- The app is not notarized yet, so after installation the cask removes the quarantine flag from `Forma.app`. Otherwise Gatekeeper blocks the first launch.
- `brew uninstall --zap --cask formacad` removes the app and its data in `~/Library` (`studio.forma.cad`).
- New versions are written by the `package-managers` job: it downloads the release `SHA256SUMS` and commits a new `Casks/formacad.rb` to the tap. It needs the `HOMEBREW_TAP_TOKEN` secret: a fine-grained token for `lovlyDev/homebrew-formacad` only, with Contents: Read and write.

## Limitations

- Betas (`-beta.N`) never go to package managers.
- Flathub needs a from-source build in its own build system, OpenCascade included. That is a separate task.
