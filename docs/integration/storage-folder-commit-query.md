# Проверка результата записи в папку

[English](storage-folder-commit-query.en.md) · [Host API](../ru/storage-folder-host-api.md)

Предложение на базе `d830ec6def86a0eac5ef11d1234c8da706749a98`.
[Точный патч](storage-folder-commit-query.patch) имеет SHA256
`a7a7e9f25065bbf46b5f6823b146f88711a77d47d70a4c98e7ca8d1ed24203d6`.
Исходники пока находятся в изолированной копии.

После неопределённого результата записи приложение может проверить ID попытки
в исходном открытии. `observe_folder_commit` получает `projectId`,
`sourceId` и `commitId`. Хост берёт окно от Tauri и вызывает чтение
сохранённой цепочки. Ответ возвращает те же три ID и статус `current`,
`historical` или `absent`. Клиент сверяет их с отправленным запросом.
`Absent` описывает состояние на момент чтения. Повторное применение
команды по этому ответу не предусмотрено.

Патч регистрирует одну команду чтения в общем `src-tauri/src/lib.rs`,
добавляет обработчик в `window_sources/ipc/{commit_query.rs}` с объявлением
в `window_sources/ipc.rs` и клиент с тестами в
`project-sources/{commitObservation.ts,commitObservation.test.ts}`.
Действие пользователя и сверка активного открытия перед обновлением сцены
относятся к следующей интеграции.

Проверены применимость патча, Rust-форматирование, TypeScript,
ESLint новых модулей и девять тестов транспорта. Компиляция Rust
обработчика ожидается после согласования.
