Дата наблюдений: 28 октября 2026. Основа FormaCAD: `4834e1020f755d4a158a105fc63965315d9c78c1`, версия 1.5.1. Blender: 5.2.3 LTS, сборка `e13b728c6880`, 22 октября 2026. Это внутренние заметки разработки, не руководство по уже выпущенным функциям FormaCAD.

Исследование выполнено собственными Python-зондами через публичный API запущенного Blender с `--factory-startup`. Исходники, декомпиляция, ресурсы, файлы тем и раскладок Blender не использовались. Записанные ниже факты пересказаны своими словами; JSON-каталоги API и раскладки остаются локально. REA 6.8.0 применён для ограниченной инспекции установленного приложения: 400 записей каталога, 18 файлов и 3360 прочитанных байтов. Это частичный структурный отчёт, не наблюдение исполнения интерфейса и не доказательство полного охвата установки.

## Воспроизводимость и ограничения

Зонды находятся в `.local/m0-preflight/probes/`, факты — в `.local/m0-preflight/facts/`, журналы — в `.local/m0-preflight/`. Эти каталоги не передаются через Git. Фоновый запуск использует `--background --factory-startup --python-exit-code 1 --python <зонд> -- --out <JSON>`. Для раскладки нужен отдельный GUI-процесс: сбор после инициализации, затем завершение только созданного процесса. Фоновый список раскладки неполон; его нельзя использовать как доказательство отсутствия сочетания.

Зонд операторов обнаружил 2498 операторов без ошибок интроспекции. Флаги доступны у 210 зарегистрированных Python-классов; `null` у остальных означает отсутствие доступных данных, а не отсутствие UNDO/REGISTER. GUI-раскладка содержит 280 карт и 3228 привязок в базовой конфигурации; это не число реализованных команд FormaCAD. Найдены 11 рабочих пространств, 1235 зарегистрированных типов панелей и 492 меню; регистрация не доказывает видимость в текущем контексте.

Для будущего изменения нужны независимые OCCT-измерения, отрицательные случаи, STEP round-trip, транзакционный откат и UI-проверки RU/EN в обеих темах. Объёмы полигональных проб Blender не являются эталоном точности B-Rep. Наличие заметки не закрывает соответствующий этап реализации.
