# Модификаторы и история

[Индекс](README.md)

**Источник.** `probe_modifiers.py`, новый куб 2×2×2 на каждый случай, публичный evaluated mesh API Blender 5.2.3.

**Поведение.** Независимые аналитические проверки: исходный объём 8; массив из трёх непересекающихся кубов с относительным смещением 1.5 по X — объём 24, X от −1 до 7; разность с кубом, сдвинутым на X=1, — объём 4. Bevel с width=0.2 и segments=3 дал полигональный объём около 7.77362018. Solidify на замкнутом кубе с thickness=0.2 дал около 2.46359806. Последние два числа — наблюдения, не аналитические критерии точной CAD-операции.

Mirror куба, пересекающего плоскость X=0, дал объём mesh 16 при прежних габаритах: наложенные оболочки нельзя считать булевым объединением или корректным единым BREP. Замкнутость рёбер mesh не доказывает отсутствие самопересечений.

**Решение FormaCAD.** Стек соответствует дереву зависимых операций. Разделять копирование, объединение и suppression. Не переносить полигональные деформации в точную модель. История сохраняет намерение и параметры; её сворачивание относится к отдельному этапу истории.

**Модули.** `cad_ir/dependencies.rs`, `history.rs`, `native/document.rs`; целевые отдельные операции shell/pattern в M3 и thicken/mirror-features в M4.

**Статус и проверка.** Новые массивы, оболочка и операции истории не реализованы этим исследованием. Проверять число тел, пересечения копий, отрицательную толщину, потерянную грань, граф зависимостей и отмену. Не сравнивать скругление OCCT с числом вершин Blender как с критерием равенства.
