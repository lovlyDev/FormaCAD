# Операторы и расширения

[Индекс](README.md) · [Платформа плагинов](../../ru/plugin-platform.md)

**Источник.** `dump_operators.py`, регистрация Panel/Menu через публичный Python API Blender; текущие WIT, схема манифеста и Rust-модули FormaCAD 1.5.1.

**Поведение.** У операторов есть идентификаторы и типизированные RNA-свойства; панели и меню регистрируются отдельно. Каталог даёт 2498 операторов, но не гарантирует доступность в любом контексте. Неизвестные флаги не считать выключенными. Исполнение Python-кода Blender не является моделью безопасности FormaCAD.

**Решение FormaCAD.** Операторы отображаются на Command API, панели — на декларативный UI, дополнения — на WASM-компоненты с узкими правами. Только пользовательские события могут подтверждать изменение. Никакого прямого доступа плагина к shell, произвольным путям, чатам и ключам. Python SDK допустим как компиляция в WASM, не обязательный Python runtime CAD.

**Модули.** `apps/desktop/src-tauri/src/plugins/`, `apps/desktop/src/features/plugins/`, `docs/plugin-api/wit/formacad-plugin.wit`, `docs/schemas/plugin-manifest.schema.json`; будущие раздельные `wit/v1/`, `runtime/v1/`, `compat_v0/`.

**Статус и проверка.** В 1.5.1 действует plugin-api 0.2 с WIT package 0.1.0 для совместимости. API 1.0, интерактивные инструменты, подписки, geometry handles, overlay и SDK ещё не реализованы. M5 должен проверять фикстуры 0.1/0.2/1.0, права на границе хоста, fuel/память/время, отсутствие плагина при cached BREP и явное обновление версии проекта.

**Серверная зависимость.** Для отдельной серверной задачи потребуются новые разрешённые WIT-импорты, проверка новых вкладов манифеста и объяснения прав RU/EN. Формат подписанного индекса сохраняется. Репозиторий FormaCAD-Server здесь не изменяется.
