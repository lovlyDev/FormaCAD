# Трансформации

[Индекс](README.md)

**Источник.** `probe_transform.py`, GUI-раскладка и отдельный зонд синтетических событий. Фоновая проба выполнила перенос X=10, поворот Z=π/2 и равномерный масштаб 2, с независимыми проверками чисел.

Отдельный фоновый случай проверил смещённую опору: поворот исходного куба на π/2 вокруг Z через (1, 0, 0) переместил его начало из (0, 0, 0) в (1, −1, 0), с независимым допуском 10⁻⁶. Это проверка параметра оператора, не взаимодействия с переключателем точки опоры в UI.

**Поведение.** Перенос, поворот и масштаб имеют разные наборы параметров. В модальной карте Enter/ЛКМ подтверждают, Esc/ПКМ отменяют; X задаёт ось, Ctrl участвует в привязке. Регистрация этих событий сама по себе не доказывает ввод единиц, отмену или undo.

**Решение FormaCAD.** Предпросмотр без геометрической ревизии; подтверждение — типизированная команда и одна транзакция; отмена — без записи. Физические коды клавиш обеспечивают работу в русской раскладке. Единицы разбираются собственным строгим парсером; формулы откладываются до 2.1.

Отдельный повторный GUI-зонд подтвердил числовое `X → 10 → Enter`: положение (10, 0, 0), а затем на заново обнулённом кубе `X → 5 → Esc`: положение (0, 0, 0). В обоих случаях оператор действительно вернул RUNNING_MODAL. Это подтверждает только синтетические числовые подтверждение/отмену без суффикса единиц; не Ctrl+Z, движение мыши или точность FormaCAD.

Дополнительный GUI-зонд с расширенным числовым вводом `X → =10mm → Enter` дал X=0.010000000707805157 в метрической сцене с scale_length=1, что соответствует 10 мм с допуском 10⁻⁶ единицы Blender; остальные координаты нулевые. Это отдельная проверка единиц, а не результат фонового execute. Не переносить её float-погрешность в критерии точного worker FormaCAD.

**Модули.** Существующие `features/feature-transforms/`, host `cad_ir/transforms.rs`, `cad_ir/commands/transforms.rs`, native `transforms.rs`; целевые `features/transform/`, `features/keymap/`, `features/adjust-last/`.

**Статус и проверка.** Модальный G/R/S, точки опоры, ориентации, привязка и F9 — открытая работа M2. Для FormaCAD обязательно проверить `10mm` по X точным измерением worker, отмену без ревизии, Ctrl+Z одним шагом, повторный конфликт F9, фокус ввода и русскую раскладку. Успех фонового оператора Blender не заменяет эти проверки.
