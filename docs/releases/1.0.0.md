# Forma 1.0.0

## English
I am releasing Forma 1.0.0 as the first public version of my CAD workspace. I can build models with parametric documents and keep local revision history. The interface supports Russian and English, light and dark themes, and restores the workspace after restarting or updating the app.

This release provides installers for Windows x64, macOS on Apple Silicon and Intel, and Linux x64. The app checks GitHub for signed updates, offers Install or Later, and backs up the local database before installing an update.

## Русский
Я выпускаю Forma 1.0.0 — первую публичную версию моей рабочей среды для CAD. В ней можно создавать параметрические модели, вести локальную историю изменений и продолжать работу после перезапуска или обновления приложения. Интерфейс доступен на русском и английском языках, со светлой и тёмной темами.

Для Windows x64, macOS на Apple Silicon и Intel, а также Linux x64 подготовлены установщики. Приложение проверяет наличие подписанных обновлений на GitHub, предлагает установить новую версию или отложить её и создаёт резервную копию локальной базы перед установкой.
