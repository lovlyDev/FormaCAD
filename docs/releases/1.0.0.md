# Forma 1.0.0

## English
First GitHub release line: Windows x64, macOS Apple Silicon / Intel and Linux x64 packaging, signed update support, Install / Later prompts, pre-update database backups and persistent workspace state. Includes bilingual UI, both themes, parametric CAD documents and local revision history. The placeholder F avatar was removed.

## Русский
Первый релиз GitHub-линейки: сборки Windows x64, macOS Apple Silicon / Intel и Linux x64, подписанные обновления, «Установить / Позже», резервные копии базы и сохранение рабочего места. Включает два языка, обе темы, параметрические CAD-документы и локальную историю. Кружок-заглушка F удалён.
