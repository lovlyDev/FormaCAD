# Forma 1.1.0

## English

I refreshed the desktop workspace in Forma 1.1.0. The top bar, project sidebar, modeling viewport, assistant panel and status bar now use a consistent floating layout with rounded surfaces and clearer spacing. I adjusted the purple accents and the viewport background and grid for both light and dark themes. Switching themes still preserves the scene and camera.

I also fixed a startup failure affecting installations with existing project databases. The Windows 1.0.0 build could embed a different checksum for the original SQL migration because Git converted its line endings during checkout. The app then closed before opening the workspace. Migration files now keep LF line endings on every platform, and CI checks the original migration checksum. This change does not rewrite or delete the database, projects or settings.

If Forma 1.0.0 closes immediately, download and install 1.1.0 from [GitHub Releases](https://github.com/lovlyDev/FormaCAD/releases/tag/v1.1.0). The in-app update prompt cannot appear while that version fails to start. Keep the existing application data directory; the installer uses it automatically.

## Русский

Я обновил рабочее пространство Forma 1.1.0. Верхняя панель, список проектов, область моделирования, панель ассистента и строка состояния теперь образуют единый интерфейс с отдельными скруглёнными панелями и более ясными отступами. Я уточнил фиолетовые акценты, фон и сетку 3D-области для светлой и тёмной тем. Переключение темы по-прежнему сохраняет сцену и камеру.

Я также исправил ошибку запуска с существующей базой проектов. В Windows-сборке 1.0.0 Git мог изменить окончания строк исходной SQL-миграции, из-за чего приложение считало уже применённую миграцию изменённой и закрывалось до открытия рабочего пространства. Теперь файлы миграций сохраняют окончания LF на всех платформах, а CI проверяет контрольную сумму исходной миграции. Исправление не переписывает и не удаляет базу, проекты или настройки.

Если Forma 1.0.0 сразу закрывается, скачайте и установите 1.1.0 из [GitHub Releases](https://github.com/lovlyDev/FormaCAD/releases/tag/v1.1.0). В таком состоянии приложение не успевает предложить обновление самостоятельно. Каталог данных оставьте на месте: установщик использует его автоматически.
