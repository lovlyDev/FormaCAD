# Forma 1.2.0

## English

I refined everyday modeling and project management in Forma 1.2.0. Right-button panning is now slower and more predictable. Isometric, Top, Front and Side rotate around the current model without changing the viewing distance, and the measurement panel has clearer spacing and sizing.

Model source edits now stay in the local editing workflow instead of adding service messages to the assistant conversation. I also separated the CadQuery runtime action from nearby content and removed repeated local-storage labels from the workspace.

Project cards now generate a model preview for the current revision. Pinning has a visible badge and animated reordering. Projects can be renamed, or permanently deleted after entering the exact project name; deletion removes the project database records, stored project directory, UI state and unreferenced attachment blobs.

This release keeps the saved project, revisions, camera, panels, theme, language and other workspace preferences when upgrading from an earlier version.

## Русский

В Forma 1.2.0 я доработал повседневное моделирование и управление проектами. Перемещение правой кнопкой мыши стало медленнее и предсказуемее. Ракурсы «Изометрия», «Сверху», «Спереди» и «Сбоку» теперь поворачивают камеру вокруг текущей модели без изменения дистанции, а панель измерений получила понятные размеры и отступы.

Изменения исходного кода модели теперь остаются в локальном редакторе и не добавляют служебные сообщения в диалог с ассистентом. Я также отделил действие выбора среды Python/CadQuery от соседнего содержимого и убрал повторяющиеся подписи о локальном хранении из рабочего пространства.

Карточки проектов автоматически получают изображение модели для текущей ревизии. Закрепление отображается заметной меткой и анимированным перемещением карточки. Проект можно переименовать или удалить навсегда после ввода его точного имени; удаление очищает записи проекта в базе, каталог проекта, состояние интерфейса и больше не используемые файлы вложений.

При обновлении с предыдущей версии сохраняются проект, ревизии, камера, панели, тема, язык и остальные параметры рабочего пространства.
