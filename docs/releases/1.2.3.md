# Forma 1.2.3

## English

I redesigned the update dialog so release notes are easy to read. It now renders Markdown headings, paragraphs, lists, emphasis, quotes, code and tables with proper spacing in both light and dark themes.

Links in the notes open in the browser. Relative links to repository documents resolve against the tagged release, while unsafe URL schemes cannot become clickable links. I also gave the version status a clearer layout and more room for longer release notes.

The project deletion dialog now shows the exact name to enter separately above an empty confirmation field.

Pinning a project now animates smoothly into its new position without stopping halfway and jumping at the end. The pinned badge and highlighted border show its new state.

Switching between perspective and orthographic views now keeps separate camera framing for each projection, so the model does not suddenly shrink. Right-button panning follows the pointer without delayed drift.

I also strengthened the cross-platform theme check to verify the WebGL scene background directly in both color themes.

Projects and workspace settings remain in place when updating. See [data and recovery](../en/data.md) and the [release guide](../en/releases.md).

## Русский

Я обновил окно установки новой версии: описание релиза теперь удобно читать. Заголовки, абзацы, списки, выделения, цитаты, код и таблицы из Markdown отображаются с правильными отступами в светлой и тёмной темах.

Ссылки в описании открываются в браузере. Относительные ссылки на документацию ведут к файлам соответствующего тега в репозитории, а небезопасные адреса не становятся кликабельными. Статус версии стал заметнее, и для длинного описания появилось больше места.

В окне удаления проекта точное название для подтверждения теперь показано отдельно над пустым полем ввода.

При закреплении карточка плавно перемещается на новое место без остановки посередине и скачка в конце. Закреплённое состояние показывают метка и выделенная рамка.

Перспективная и ортографическая проекции теперь сохраняют свои параметры камеры отдельно: при переключении модель больше не становится внезапно крошечной. Перемещение правой кнопкой мыши следует за курсором без запаздывающего дрейфа.

Проверка тем на разных платформах теперь сверяет цвет самой WebGL-сцены в обоих режимах.

При обновлении проекты и настройки рабочего места сохраняются. Подробнее: [данные и восстановление](../ru/data.md) и [руководство по релизам](../ru/releases.md).
