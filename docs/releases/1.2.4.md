# Forma 1.2.4

## English

I restored the compact project deletion confirmation. The project name to enter now appears in bold within the instruction, immediately above the empty field. The exact-name check still prevents accidental deletion.

Local geometry builds no longer show an AI-agent task in the chat. The status bar reports the current local operation; the chat progress panel appears only while the agent is running.

Projects and workspace settings remain in place when updating. See [data and recovery](../en/data.md) and the [release guide](../en/releases.md).

## Русский

Я вернул компактное подтверждение удаления проекта. Название, которое нужно ввести, теперь выделено жирным прямо в строке над пустым полем. Удаление по-прежнему доступно только после точного ввода названия.

Локальное построение геометрии больше не показывает задачу ИИ-агента в чате. Текущая операция видна в строке состояния, а панель прогресса в чате появляется только во время работы агента.

При обновлении проекты и настройки рабочего места сохраняются. Подробнее: [данные и восстановление](../ru/data.md) и [руководство по релизам](../ru/releases.md).
