# Forma 1.3.0

[Русский статус](../ru/status.md) · [English status](../en/status.md)

## Русский

Локальный этап архитектурной 2.0: статус истории, чтение вложений, свойства сохранённого STEP, предпросмотр черновика и ручное сечение используют чистое сохранённое состояние. Они не завершают восстановление файловой публикации неявно; при незавершённом журнале пользователь получает сообщение о повторном открытии проекта. Источник повторно проверяется перед возвратом результата. Полное описание и исходные STEP-файлы остаются отдельными проверяемыми границами.

История и ручные CAD-операции сохраняют свои существующие кнопки; импортированный STEP не требует авторского CAD IR для свойств или ручного сечения. Восстановление при обычном открытии и операции записи остаются отдельными маршрутами. Более строгая проверка полного снимка может потребовать повторного запроса при параллельном изменении метаданных.

Подробности: [снимки проекта](../ru/project-snapshots.md). Это не полный live repository/session registry и не самостоятельное открытие внешней папки. Windows-установщик проверен и опубликован 11 октября 2026 года по прямому поручению пользователя. Установка не выполнялась.
