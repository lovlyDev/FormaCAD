# Forma 1.3.2

[Русский статус](../ru/status.md) · [English status](../en/status.md)

## Русский

Обновлены уязвимые зависимости Zod, TLS, Tokio и ZIP. Исправленная ZIP-зависимость используется и для `.cadpack`, и внутри updater; подписи и платформенные механизмы обновления сохраняются. Происхождение минимального патча upstream и проверка описаны в [руководстве разработчика](../ru/development.md).

Интерфейс Windows больше не импортирует OCCT напрямую: нативные построения, STEP, измерения и сечения выполняет отдельный CAD worker. Проверка готовности запускает реальную операцию ядра с ограниченным временем. Отсутствие CAD DLL должно обрабатываться как недоступность worker; причина прежней ошибки на другом компьютере не устанавливается по одному скриншоту.

Установщик включает проверяемый Microsoft runtime и лицензии OCCT. Сборка проверяет архитектуру, подписи и хеши runtime, а также импорты desktop. Подпись обновления не является Authenticode-подписью Windows; совместимость с политикой Smart App Control требует отдельной проверки.

Абсолютный `FORMA_DATA_DIR` задаёт отдельный профиль для базы, проектов, журналов, настроек окна и стандартного хранилища WebView. Некорректный путь отклоняется до запуска плагинов. Оформление, конфиденциальность и разрешения больше не запускают неиспользуемые проверки внешних AI/CAD-программ. Назначение, маршрут данных и ограничения описаны в [руководстве разработчика](../ru/development.md).

Архитектурная 2.0 остаётся незавершённой. Сборки и автоматические тесты не заменяют установленную приёмку на всех ОС, проверку NAS/съёмных носителей и политики Windows. Результаты конкретного CI и проверки установщика сопровождают публикацию. Старые релизы и пользовательские данные сохраняются; установка не выполняется автоматически.

## English

Vulnerable Zod, TLS, Tokio and ZIP dependencies are updated. Both `.cadpack` and the updater use the patched ZIP dependency while retaining signature checks and platform update mechanisms. The minimal upstream patch's provenance and verification are documented in the [development guide](../en/development.md).

The Windows desktop no longer imports OCCT directly: a separate CAD worker retains native building, STEP, measurements and sections. Readiness performs a real bounded kernel operation. Missing CAD DLLs should be handled as worker unavailability; a screenshot alone does not establish the cause of an earlier error on another computer.

The installer includes verified Microsoft runtime files and OCCT licenses. Packaging checks runtime architecture, signatures and hashes, and desktop imports. An updater signature is not Windows Authenticode; Smart App Control compatibility requires separate acceptance.

An absolute `FORMA_DATA_DIR` selects an independent profile for the database, projects, logs, window settings and default WebView storage. Invalid paths fail before plugin startup. Appearance, privacy and permissions no longer launch unused external AI/CAD environment probes. Usage, data routing and limitations are in the [development guide](../en/development.md).

Architectural 2.0 remains unfinished. Builds and automated tests do not replace installed acceptance on every OS, NAS/removable-media checks or Windows policy validation. The publication includes results for its specific CI run and installer. Previous releases and user data remain preserved; installation is not automatic.
