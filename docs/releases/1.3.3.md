# Forma 1.3.3

[Русский статус](../ru/status.md) · [English status](../en/status.md)

## Русский

Необязательный вход в аккаунт FormaCAD прямо из приложения: значок пользователя в верхней панели открывает системный браузер с сайтом https://formacad.ru, где вход выполняется через VK ID, Яндекс ID, GitHub или ключ доступа (passkey) и подтверждается кнопкой «Разрешить». Способы входа задаёт сайт, поэтому новые появляются без обновления приложения. Используется OAuth 2.0 с PKCE и одноразовым адресом `127.0.0.1`; токены остаются в Rust-части, refresh token — в хранилище учётных данных Windows. Права приходят подписанным документом и действуют офлайн ограниченный срок. Проекты, моделирование и экспорт по-прежнему работают без аккаунта и без сети. Подробнее — [аккаунт FormaCAD](../ru/account.md).

Исправлено удаление проекта на Windows: ошибка «Отказано в доступе (os error 5)» возникала потому, что файл блокировки хранилища внутри папки проекта оставался открытым во время её переименования. Установщик удаляет оставшийся от старых версий файл `licenses\occt`, из-за которого обновление сообщало об ошибке записи лицензий OCCT. Влита работа wenlixxq: статус undo/redo читается в рамках сеанса репозитория ([PR №5](https://github.com/lovlyDev/FormaCAD/pull/5)).

Проверено локально: Rust 165 тестов (+сквозной вход против запущенного сервера), frontend 202 теста, clippy `-D warnings`, i18n и документация. Опубликован только Windows x64 установщик с подписью обновлений Tauri; Authenticode-подписи Windows нет, поэтому SmartScreen может предупредить при первом запуске. macOS и Linux в этом выпуске не собирались. Установка на компьютер не выполняется автоматически: обновление предложит само приложение.

## English

Optional FormaCAD account sign-in from the app: the user icon in the top bar opens the system browser on https://formacad.ru, where the user signs in with VK ID, Yandex ID, GitHub or a passkey and clicks “Allow”. The site defines the sign-in methods, so new ones appear without an app update. OAuth 2.0 with PKCE and a one-shot `127.0.0.1` address is used; tokens stay in the Rust host and the refresh token is kept in the Windows credential store. Rights arrive as a signed document valid offline for a bounded period. Projects, modeling and export keep working without an account or network. Details: [FormaCAD account](../en/account.md).

Fixed project deletion on Windows: “Access is denied (os error 5)” appeared because the storage lock file inside the project folder stayed open while the folder was renamed. The installer removes the `licenses\occt` file left by old versions, which made updates report an OCCT license write error. Merged work by wenlixxq: undo/redo status is read within a repository session ([PR #5](https://github.com/lovlyDev/FormaCAD/pull/5)).

Verified locally: Rust 165 tests (plus an end-to-end sign-in against a running server), frontend 202 tests, clippy `-D warnings`, i18n and docs. Only the Windows x64 installer is published, with a Tauri updater signature; there is no Windows Authenticode signature, so SmartScreen may warn on first launch. macOS and Linux were not built for this release. Nothing is installed automatically: the app itself offers the update.
