# Forma 1.3.3

[Русский статус](../ru/status.md) · [English status](../en/status.md)

## Русский

Необязательный вход в аккаунт FormaCAD прямо из приложения: значок пользователя в верхней панели открывает системный браузер с сайтом https://cad.kartochk1n.ru, где вход выполняется через VK ID и подтверждается кнопкой «Разрешить». Используется OAuth 2.0 с PKCE и одноразовым адресом `127.0.0.1`; токены остаются в Rust-части, refresh token — в хранилище учётных данных Windows. Права приходят подписанным документом и действуют офлайн ограниченный срок. Проекты, моделирование и экспорт по-прежнему работают без аккаунта и без сети. Подробнее — [аккаунт FormaCAD](../ru/account.md).

Исправлено удаление проекта на Windows: ошибка «Отказано в доступе (os error 5)» возникала потому, что файл блокировки хранилища внутри папки проекта оставался открытым во время её переименования. Установщик удаляет оставшийся от старых версий файл `licenses\occt`, из-за которого обновление сообщало об ошибке записи лицензий OCCT. Влита работа wenlixxq: статус undo/redo читается в рамках сеанса репозитория ([PR №5](https://github.com/lovlyDev/FormaCAD/pull/5)).

Проверено локально: Rust 165 тестов (+сквозной вход против запущенного сервера), frontend 202 теста, clippy `-D warnings`, i18n и документация. Установщик собран локально и не опубликован; Authenticode-подписи нет.

## English

Optional FormaCAD account sign-in from the app: the user icon in the top bar opens the system browser on https://cad.kartochk1n.ru, where the user signs in with VK ID and clicks “Allow”. OAuth 2.0 with PKCE and a one-shot `127.0.0.1` address is used; tokens stay in the Rust host and the refresh token is kept in the Windows credential store. Rights arrive as a signed document valid offline for a bounded period. Projects, modeling and export keep working without an account or network. Details: [FormaCAD account](../en/account.md).

Fixed project deletion on Windows: “Access is denied (os error 5)” appeared because the storage lock file inside the project folder stayed open while the folder was renamed. The installer removes the `licenses\occt` file left by old versions, which made updates report an OCCT license write error. Merged work by wenlixxq: undo/redo status is read within a repository session ([PR #5](https://github.com/lovlyDev/FormaCAD/pull/5)).

Verified locally: Rust 165 tests (plus an end-to-end sign-in against a running server), frontend 202 tests, clippy `-D warnings`, i18n and docs. The installer was built locally and is not published; there is no Authenticode signature.
