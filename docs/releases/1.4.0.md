# Forma 1.4.0

[Русский статус](../ru/status.md) · [English status](../en/status.md)

## Русский

Плагины. FormaCAD устанавливает и выполняет плагины — WebAssembly-компоненты по контракту `plugin-api 0.1`: новые параметрические операции, команды, импорт и экспорт форматов, панели и настройки. Плагин работает в песочнице Wasmtime (новый экземпляр на вызов, ограничение вычислений, 256 МБ памяти, 10 с) и видит только те функции FormaCAD, на которые пользователь дал права; файлы, сеть и программы компьютера ему недоступны. Результат плагина проходит те же проверки, что и обычная правка модели, и сохраняется одной ревизией, которую можно отменить.

- «Настройки → Плагины»: установка из файла `.cadplugin`, включение, права, настройки плагина, журнал вызовов, выбор версии, удаление.
- Окно установки показывает автора, версию, источник, контрольную сумму и права простыми словами; новые права в обновлении отмечены и требуют согласия.
- Действия плагинов — в палитре команд (`Ctrl K`), формы параметров строятся из манифеста.
- Каталог [plugins.formacad.ru](https://plugins.formacad.ru): кнопка «Добавить в FormaCAD» открывает ссылку `formacad://plugins/install`. FormaCAD скачивает пакет только с каталога и проверяет подпись записи встроенным ключом каталога и SHA-256. Авторы публикуют плагины GitHub-релизами через GitHub App «FormaCAD Plugins».
- Пример `simple-gear` и инструмент `cadplugin pack` для авторов.

Подробнее: [Плагины](../ru/plugins.md), [руководство автора](../ru/plugin-authoring.md), [спецификация платформы](../ru/plugin-platform.md).

Ограничения: операция плагина сохраняется как обычные операции CAD (тело остаётся без плагина, но повторно открыть операцию с параметрами нельзя); панели открываются окном из палитры; если FormaCAD уже запущен, ссылка `formacad://` на Windows открывает второе окно. Установщики собраны в GitHub Actions и подписаны ключом обновлений Tauri: Windows x64 (NSIS), Linux x64 (AppImage, DEB, RPM) и macOS ARM (DMG). macOS Intel в этот выпуск не вошла: её сборка не успела завершиться. Подписей Authenticode и Apple нет: SmartScreen и Gatekeeper могут предупредить при первом запуске. Проверялся только Windows; Linux и macOS собраны тем же CI, но вручную не запускались.

Проверено: Rust 199 тестов (2 пропущены: нужен запущенный сервер), frontend 207 тестов, clippy `-D warnings`, rustfmt, ESLint, сборка TypeScript, i18n, документация и миграции. CI PR №10 прошёл на Windows, macOS (ARM и Intel) и Linux, включая сквозной тест плагина-примера с OCCT. Подписи обновлений всех опубликованных пакетов проверены открытым ключом приложения. Установка на компьютер не выполняется автоматически: обновление предложит само приложение.

## English

Plugins. FormaCAD installs and runs plugins — WebAssembly components following the `plugin-api 0.1` contract: new parametric features, commands, file importers and exporters, panels and settings. A plugin runs in a Wasmtime sandbox (a fresh instance per call, a compute budget, 256 MB of memory, 10 s) and sees only the FormaCAD functions the user granted; files, network and programs on the computer are out of its reach. A plugin's result goes through the same checks as a normal model edit and is saved as one revision that can be undone.

- “Settings → Plugins”: install from a `.cadplugin` file, enable, permissions, plugin settings, call log, version choice, removal.
- The install window shows the author, version, source, checksum and permissions in plain words; new permissions in an update are marked and need consent.
- Plugin actions live in the command palette (`Ctrl K`); parameter forms are built from the manifest.
- The [plugins.formacad.ru](https://plugins.formacad.ru) catalog: “Add to FormaCAD” opens a `formacad://plugins/install` link. FormaCAD downloads the package only from the catalog and verifies the entry signature with the built-in catalog key and the SHA-256. Authors publish plugins as GitHub releases through the “FormaCAD Plugins” GitHub App.
- The `simple-gear` example and the `cadplugin pack` tool for authors.

Details: [Plugins](../en/plugins.md), [author guide](../en/plugin-authoring.md), [platform specification](../en/plugin-platform.md).

Limitations: a plugin feature is stored as ordinary CAD features (the body stays without the plugin, but the feature cannot be reopened with its parameters); panels open as a window from the palette; if FormaCAD is already running, a `formacad://` link opens a second window on Windows. Installers were built in GitHub Actions and signed with the Tauri updater key: Windows x64 (NSIS), Linux x64 (AppImage, DEB, RPM) and macOS ARM (DMG). macOS Intel is not part of this release: its build did not finish in time. There are no Authenticode or Apple signatures, so SmartScreen and Gatekeeper may warn on first launch. Only Windows was checked; Linux and macOS come from the same CI but were not run by hand.

Verified: Rust 199 tests (2 skipped: they need a running server), frontend 207 tests, clippy `-D warnings`, rustfmt, ESLint, TypeScript build, i18n, docs and migrations. CI for PR #10 passed on Windows, macOS (ARM and Intel) and Linux, including the end-to-end example plugin test with OCCT. Updater signatures of all published packages were verified against the app public key. Nothing is installed automatically: the app itself offers the update.
