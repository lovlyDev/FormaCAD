# Forma 1.5.0

[Русский статус](../ru/status.md) · [English status](../en/status.md)

## Русский

plugin-api 0.2: плагины могут записывать видео вращения модели. Новое право `viewport.capture` и интерфейс хоста `viewport.record-orbit`: плагин передаёт параметры облёта (разрешение до 3840 × 2160, 1–120 кадров/с, длительность или число оборотов, направление, ось «вверх», наклон детали, высота камеры, масштаб, фон, MP4/H.264 или WebM/VP9, битрейт), а FormaCAD спрашивает, куда сохранить файл, сам рендерит каждый кадр копии модели из 3D-вида и кодирует видео средствами системы (WebCodecs). Плагин не получает ни геометрию, ни кадры, ни путь к файлу. Окно «Запись видео» показывает прогресс; «Остановить» удаляет недописанный файл.

- Команды плагинов больше не требуют `model.write`, если ничего не меняют в модели; для них не показывается окно подтверждения правки. Команда без `model.write`, вернувшая изменения, отклоняется.
- Кнопка формы команды плагина называется «Выполнить» (раньше «Построить»).
- Плагины для plugin-api 0.1 работают без пересборки: имя WIT-пакета `formacad:plugin@0.1.0` не изменилось. Плагин, импортирующий `viewport`, обязан объявить `"api": "0.2"`.

Подробнее: [Плагины](../ru/plugins.md#запись-видео-вращения), [спецификация, раздел 12](../ru/plugin-platform.md#12-уточнения-реализации), [руководство автора](../ru/plugin-authoring.md#пример-запись-видео-plugin-api-02).

Ограничения: записывается только модель (без сетки, выделения и размеров); нужен WebCodecs с кодировщиком H.264 или VP9/VP8 — на Windows (WebView2) и macOS он есть, на Linux зависит от WebKitGTK и GStreamer; не больше 36 000 кадров и 4 ГБ.

Проверено: `cargo test --lib plugins::` — 34 теста, включая сквозную установку компонента, который вызывает `viewport.record-orbit`, отказ без права, отказ при `"api": "0.1"`, отказ команды без `model.write`, проверку диапазонов и запись файла по смещениям; `vitest` для плагинов (математика облёта, формы, окно установки); сборка TypeScript, ESLint, `check:i18n`, `check:docs`. Опубликована 28 октября 2026 года из merge-коммита PR №13 (`d9b1e92`, тег `v1.5.0`): Release workflow собрал и подписал установщики Windows x64 (NSIS), Linux x64 (AppImage, DEB, RPM), macOS ARM и macOS Intel (DMG); `latest.json` содержит все четыре платформы, SHA-256 установщика Windows совпадает с SHA256SUMS. Запись видео в установленном приложении не проверялась: кодирование MP4/WebM проверено только во временном стенде Chromium.

## English

plugin-api 0.2: plugins can record turntable videos of the model. A new `viewport.capture` permission and the `viewport.record-orbit` host interface: the plugin passes the orbit settings (up to 3840 × 2160, 1–120 fps, length or number of turns, direction, up axis, part tilt, camera height, zoom, background, MP4/H.264 or WebM/VP9, bitrate), and FormaCAD asks where to save the file, renders every frame of a copy of the model in the 3D view and encodes the video with the system's encoders (WebCodecs). The plugin never receives the geometry, the frames or the file path. The “Recording video” window shows progress; Stop deletes the unfinished file.

- Plugin commands no longer need `model.write` when they change nothing in the model, and no model-edit approval is shown for them. A command without `model.write` that returns changes is rejected.
- The plugin command form button now reads “Run” (was “Build”).
- plugin-api 0.1 plugins keep working without a rebuild: the WIT package name `formacad:plugin@0.1.0` is unchanged. A plugin that imports `viewport` must declare `"api": "0.2"`.

Details: [Plugins](../en/plugins.md#turntable-video-recording), [specification, section 12](../en/plugin-platform.md#12-implementation-notes), [author guide](../en/plugin-authoring.md#example-recording-a-video-plugin-api-02).

Limitations: only the model is recorded (no grid, selection or dimensions); WebCodecs with an H.264 or VP9/VP8 encoder is required — available on Windows (WebView2) and macOS, on Linux it depends on WebKitGTK and GStreamer; at most 36,000 frames and 4 GB.

Verified: `cargo test --lib plugins::` — 34 tests, including end-to-end installation of a component that calls `viewport.record-orbit`, refusal without the permission, refusal with `"api": "0.1"`, refusal of a command without `model.write`, range checks and writing the file at offsets; `vitest` for plugins (orbit math, forms, install window); TypeScript build, ESLint, `check:i18n`, `check:docs`. Published on 28 October 2026 from the PR #13 merge commit (`d9b1e92`, tag `v1.5.0`): the Release workflow built and signed Windows x64 (NSIS), Linux x64 (AppImage, DEB, RPM), macOS ARM and macOS Intel (DMG) installers; `latest.json` lists all four platforms and the Windows installer SHA-256 matches SHA256SUMS. Video recording was not checked in the installed app: MP4/WebM encoding was only checked in a temporary Chromium harness.
