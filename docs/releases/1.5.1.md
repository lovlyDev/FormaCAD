# Forma 1.5.1

[Русский статус](../ru/status.md) · [English status](../en/status.md)

## Русский

Действия плагинов в панели инструментов 3D-вида: операция или команда со значком из манифеста получает свою кнопку с этим значком, остальные действия собраны в меню «Действия плагинов» (значок пазла) — тот же список, что в палитре команд (`Ctrl K`). Кнопки видны, только когда у включённых плагинов есть действия; меню закрывается по `Esc` или щелчку вне его. Список поддерживаемых значков — в [руководстве автора](../ru/plugin-authoring.md#кнопка-в-панели-3d-вида). Работает в светлой и тёмной темах. Подробнее: [Плагины](../ru/plugins.md#использование).

Проверено: `vitest` для плагинов (кнопки и меню: скрыты без действий, кнопка по значку, меню открывает выбранное действие), сборка TypeScript, ESLint, `check:i18n`, `check:docs`; вид кнопки и меню в обеих темах. Установщики собирает Release workflow в GitHub Actions.

## English

Plugin actions in the 3D-view toolbar: a feature or command with a manifest icon gets its own button with that icon; the rest are in the “Plugin actions” menu (puzzle icon), the same list as the command palette (`Ctrl K`). The buttons show only while enabled plugins have actions; the menu closes on `Esc` or a click outside. Supported icons are listed in the [author guide](../en/plugin-authoring.md#button-in-the-3d-view-toolbar). Works in the light and dark themes. Details: [Plugins](../en/plugins.md#using-plugins).

Verified: plugin `vitest` (buttons and menu: hidden without actions, icon button, the menu opens the chosen action), TypeScript build, ESLint, `check:i18n`, `check:docs`; the button and menu in both themes. Installers are built by the Release workflow in GitHub Actions.
