# Forma 1.6.0

[Русский статус](../ru/status.md) · [English status](../en/status.md)

## Русский

**3D-вид в стиле Blender (M2).** Клавишами G/R/S тела перемещаются, поворачиваются и масштабируются; можно ввести точное значение, ограничить ось (X/Y/Z, повторное нажатие — локальная ось тела). F9 меняет параметры последней трансформации. Выделение: Shift, A/Alt+A/Ctrl+I, рамка B, кисть C, лассо Ctrl+ПКМ; в сплошных режимах берутся только видимые тела. Видимость: H, Shift+H, Alt+H, изоляция. Добавлены 7 стандартных видов, круговые меню Z, «.» и Shift+S, 3D-курсор и пресет мыши Blender. Точные привязки через OCCT: грань, середина ребра, центр окружности, вершины бокса; режим вершин (4), привязка перемещения к вершине, линейка и угломер. Все изменения геометрии идут через обычный Command API с перестроением в изолированном процессе OCCT и атомарным сохранением ревизии. Подробнее: [Viewport и модальные трансформации](../ru/viewport-transforms.md).

**Области и рабочие пространства (M1).** Рабочая область — дерево областей с редакторами: 3D-вид, модель, файлы, параметры, AI, свойства, история, задачи, активность, журналы. Области можно разделять, объединять и менять местами. Готовые раскладки «Модель», «Проверка» и «Эскиз» меняют расположение панелей, а не геометрию. Подробнее: [Области, рабочие пространства и редакторы](../ru/workspace-areas.md).

**Оформление.** Главное меню перенесено в верхнюю панель. Цветные обводки убраны во всех темах, заголовки областей плоские, 3D-вид без рамки. Анимации ускорены до 90–140 мс. Оверлеи 3D-вида подстраиваются под ширину своей области, верхняя панель всегда помещается в окно.

**Безопасность.** Wasmtime обновлён до 50.0.1 (RUSTSEC-2026-0422, 0423, 0424) — песочница плагинов.

Ограничения: тела трансформируются целиком, режима правки отдельных вершин, рёбер и граней BREP нет. Точное уточнение вершин через OCCT есть только у боксов; у цилиндров, булевых операций, скруглений и STEP вершины берутся по координатам предпросмотра и помечены как приблизительные. F9 работает только для последней трансформации текущего сеанса.

Проверено: CTest 17/17, Rust lib 272 и интеграционные тесты, strict Clippy, fmt, Vitest 278, Playwright 84 пройдено / 0 упало, спека M2 6/6, `check:i18n`, `check:docs`, `check:migrations`; собранное приложение с настоящим OCCT (G X 10 → 30 мм, F9 25 → 45, вершина и линейка точно). CI на GitHub зелёный на Windows, Linux, macOS ARM и macOS Intel. Установщики собирает Release workflow в GitHub Actions.

## English

**Blender-style 3D viewport (M2).** G/R/S move, rotate and scale bodies with exact typed values and axis constraints (X/Y/Z; pressing again uses the body's local axis). F9 adjusts the last transform. Selection: Shift, A/Alt+A/Ctrl+I, box B, brush C, lasso Ctrl+RMB; solid shading picks only visible bodies. Visibility: H, Shift+H, Alt+H, isolation. Seven standard views, Z, "." and Shift+S pie menus, a 3D cursor and a Blender mouse preset. Exact OCCT snapping: face, edge midpoint, circle centre, box vertices; vertex mode (4), vertex-snapped moves, ruler and protractor. Every geometry change goes through the regular Command API with an OCCT rebuild in the isolated worker and an atomic revision save. Details: [Viewport and modal transforms](../en/viewport-transforms.md).

**Areas and workspaces (M1).** A workspace is a tree of editor areas: viewport, model, files, parameters, AI, properties, history, tasks, activity, logs. Areas split, merge and swap. The Model, Inspect and Sketch presets rearrange panels without changing geometry. Details: [Areas, workspaces and editors](../en/workspace-areas.md).

**Look and feel.** The main menu now lives in the top bar. Coloured outlines are gone in every theme, area headers are flat and the viewport has no frame. Motion is faster (90–140 ms). Viewport overlays size to their own area and the top bar always fits the window.

**Security.** Wasmtime updated to 50.0.1 (RUSTSEC-2026-0422, 0423, 0424) for the plugin sandbox.

Limitations: bodies are transformed whole; there is no edit mode for individual BREP vertices, edges or faces. Exact OCCT vertex refinement exists only for boxes; cylinders, booleans, fillets and STEP use preview coordinates and are labelled approximate. F9 covers only the last transform of the current session.

Verified: CTest 17/17, Rust lib 272 plus integration tests, strict Clippy, fmt, Vitest 278, Playwright 84 passed / 0 failed, M2 spec 6/6, `check:i18n`, `check:docs`, `check:migrations`; the built app with real OCCT (G X 10 → 30 mm, F9 25 → 45, exact vertex and ruler). GitHub CI is green on Windows, Linux, macOS ARM and macOS Intel. Installers are built by the Release workflow in GitHub Actions.
