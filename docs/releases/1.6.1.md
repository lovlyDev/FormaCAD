# Forma 1.6.1

[Русский статус](../ru/status.md) · [English status](../en/status.md)

## Русский

Исправления 3D-вида после 1.6.0:

- **«Вписать модель» и Home** вписывают модель в кадр по описанной сфере с запасом 15% и сохраняют направление взгляда. Раньше камера при каждом нажатии только отдалялась, а в пустом проекте улетала далеко; теперь пустой проект показывает область 100 мм вокруг начала координат. Подробнее: [Viewport и модальные трансформации](../ru/viewport-transforms.md).
- **Панель измерения** («Расстояние — выберите точку 1 из 2») больше не сжимается в узкую полоску рядом с панелью инструментов.
- **Кнопки «Инструменты» и «Элемент»** в заголовке 3D-вида убраны: по щелчку они ничего не делали. Панель инструментов и боковая панель переключаются клавишами T и N, подсказка есть в строке состояния. Подробнее: [Области и рабочие пространства](../ru/workspace-areas.md).
- **Меню браузера** по правой кнопке мыши («Назад», «Обновить», «Сохранить как», «Печать») больше не появляется. В текстовых полях остаются вырезание, копирование и вставка; круговые меню, лассо и панорамирование правой кнопкой работают как прежде.

Проверено: Vitest 280 тестов, в том числе новый тест подавления меню; `check:i18n`, `check:docs`; CI на GitHub, включая e2e, зелёный на Windows, Linux, macOS ARM и macOS Intel. Установщики собирает Release workflow в GitHub Actions.

## English

Viewport fixes after 1.6.0:

- **Fit model and Home** frame the model by its bounding sphere with a 15% margin and keep the view direction. Before, every press only pushed the camera back, and an empty project flew far away; an empty project now shows a 100 mm area around the origin. Details: [Viewport and modal transforms](../en/viewport-transforms.md).
- **The measure panel** ("Distance — pick point 1 of 2") no longer collapses into a narrow strip next to the toolbar.
- **The Tools and Item buttons** in the viewport header are gone: clicking them did nothing. T and N toggle the toolbar and the sidebar, with a hint in the status bar. Details: [Areas and workspaces](../en/workspace-areas.md).
- **The browser menu** on right-click (Back, Reload, Save as, Print) no longer appears. Text fields keep cut, copy and paste; right-click pie menus, lasso and panning work as before.

Verified: Vitest 280 tests, including a new menu-suppression test; `check:i18n`, `check:docs`; GitHub CI including e2e is green on Windows, Linux, macOS ARM and macOS Intel. Installers are built by the Release workflow in GitHub Actions.
