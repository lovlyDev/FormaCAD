# Forma 1.6.2

[Русский статус](../ru/status.md) · [English status](../en/status.md)

## Русский

Бета-канал для сторонников:

- **Канал обновлений.** После входа в аккаунт FormaCAD в окне «Обновления» появляется выбор «Стабильный» или «Бета (для сторонников)». Он есть, если в документе аккаунта есть право `beta.access`, то есть пока действует статус сторонника; у администраторов — всегда. Выбор сохраняется. Без входа и без права используется стабильный канал. Подробнее: [Настройки и обновления](../ru/settings-and-updates.md).
- **Как идёт обновление.** Бета-версию проверяет и скачивает сервер аккаунта, токен входа остаётся в Rust-части приложения. Подпись бета-обновления проверяется тем же ключом, что и у стабильных версий.
- Новых инструментов моделирования в 1.6.2 нет: они проходят проверку в бете 1.7.0-beta.1.

Проверено: CI на GitHub, включая e2e, на Windows, Linux, macOS ARM и macOS Intel; `check:i18n`, `check:docs`, `check:migrations`; локальная сборка установщика Windows.

## English

Supporter beta channel:

- **Update channel.** After signing in to a FormaCAD account, the Updates dialog offers Stable or Beta (for supporters). It appears when the account document grants `beta.access`, i.e. while supporter status lasts; administrators always have it. The choice is saved. Signed out or without the right, the stable channel is used. Details: [Settings and updates](../en/settings-and-updates.md).
- **How the update runs.** The account server checks and serves beta builds; the sign-in token stays in the Rust host. Beta updates are verified with the same signing key as stable ones.
- 1.6.2 adds no new modeling tools: they are being tested in the 1.7.0-beta.1 beta.

Verified: GitHub CI including e2e on Windows, Linux, macOS ARM and macOS Intel; `check:i18n`, `check:docs`, `check:migrations`; a local Windows installer build.
