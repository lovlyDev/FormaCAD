# Forma 1.7.0-beta.1

[Русский статус](../ru/status.md) · [English status](../en/status.md)

## Русский

Приватная бета для сторонников проекта: проверка инструментов моделирования M3 перед стабильным выпуском 1.7.0. Бета не меняет открытый канал обновлений и раздел «Последний релиз». Получить её можно на сайте в разделе «Сторонник» или переключив канал обновлений в приложении на бету после входа в аккаунт. Подробнее о канале: [Выпуски](../ru/releases.md#бета-выпуски).

Новое в инструментах моделирования (M3), подробнее в разделе [Моделирование](../ru/modeling.md):

- **Тор** из меню «Добавить», с поправкой обоих радиусов через F9.
- **Опорные плоскости, оси и точки** по координатам модели или с привязкой к грани, ребру или другой опорной плоскости.
- **Вытягивание грани** клавишей E или стрелкой по нормали: положительное расстояние добавляет материал, отрицательное вырезает.
- **Скругление и фаска** по нескольким рёбрам сразу (Ctrl+B), включая круговые кромки цилиндра, с точным предпросмотром OCCT.
- **Оболочка** с несколькими проёмами, стенки внутрь или наружу.
- **Линейный и круговой массивы** тела или отверстия.
- **Дублирование (Shift+D), разделение составного тела (P) и группы тел** в дереве модели.
- **Булевы операции** объединения, вычитания и пересечения с сохранением тела-инструмента.
- **Умный выбор:** похожие элементы (Shift+G), связанное тело (L) и касательная цепочка (Alt+щелчок).
- **Снимок вида в PNG** до 3× с прозрачным фоном, **журнал активности** с правками, отменами и повторами, **«Копировать как команду»** для Command API и **редактор тем** с проверкой контраста.

Также после 1.6.1: лицензия GPL-3.0-or-later и политика подписи кода, установка через winget, аттестации артефактов GitHub.

Встроенная SQLite остаётся версии ниже 3.54 (RUSTSEC-2026-0459): ни одна версия SQLx ещё не принимает исправленную библиотеку. Уязвимость требует подложить подготовленные файлы в папку данных Forma; чужие базы SQLite приложение не открывает. Обновим, как только SQLx её поддержит.

Проверено: CI на всех платформах для M3. В собранном приложении (русский язык, светлая тема, настоящий OCCT) объёмы скругления, фаски, булевых операций, оболочки, массива, дублирования, вытягивания и тора совпали с расчётом, а пустое пересечение отклоняется без новой ревизии. Вживую не проверялись опорные элементы, сохранение PNG и редактор тем, а также macOS и Linux.

## English

A private beta for project supporters, to test the M3 modeling tools before the stable 1.7.0 release. The beta does not change the public update channel or the "Latest release". Get it from the Supporter page on the website, or sign in and switch the app's update channel to beta. About the channel: [Releases](../en/releases.md).

New modeling tools (M3), details in [Modeling](../en/modeling.md):

- **Torus** from the Add menu, with both radii adjustable through F9.
- **Datum planes, axes and points** at model coordinates or anchored to a face, an edge or another datum plane.
- **Extrude face** with E or the normal arrow: a positive distance adds material, a negative one cuts.
- **Fillet and chamfer** on several edges at once (Ctrl+B), including circular cylinder edges, with an exact OCCT preview.
- **Shell** with several openings, walls inward or outward.
- **Linear and circular patterns** of a body or a hole.
- **Duplicate (Shift+D), separate a compound body (P) and body groups** in the model tree.
- **Boolean union, cut and intersect** that keep the tool body.
- **Smart selection:** similar elements (Shift+G), linked body (L) and tangent chain (Alt+click).
- **PNG viewport snapshot** up to 3× with a transparent background, an **activity log** of edits, undos and redos, **Copy as command** for the Command API, and a **theme editor** with contrast checks.

Also since 1.6.1: GPL-3.0-or-later licence and code signing policy, winget installation, GitHub artifact attestations.

The bundled SQLite stays below 3.54 (RUSTSEC-2026-0459): no SQLx release accepts the patched library yet. Exploiting it requires planting crafted files in the Forma data folder; the app never opens a SQLite file from elsewhere. We will update as soon as SQLx supports it.

Verified: CI on every platform for M3. In the built app (Russian, light theme, real OCCT) fillet, chamfer, Boolean, shell, pattern, duplicate, extrude and torus volumes matched the analytic values, and an empty intersection is rejected without a new revision. Not checked live: datums, saving the PNG and the theme editor, and macOS and Linux.
