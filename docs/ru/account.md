# Аккаунт FormaCAD в приложении

[Документация](index.md) · [English](../en/account.md) · [Настройки и обновления](settings-and-updates.md) · [Данные](data.md)

## Назначение

Вход в аккаунт FormaCAD необязателен. Проекты, моделирование, история, импорт и экспорт работают без аккаунта, без оплаты и без подключения к серверу. Аккаунт нужен для поддержки, подписки и будущих сервисов. Окончание подписки, недоступность сервера или выход из аккаунта не удаляют и не блокируют модели.

## Действия пользователя

1. В верхней панели нажмите значок пользователя → «Войти через браузер».
2. Откроется системный браузер с сайтом FormaCAD. Войдите удобным способом — VK ID, Яндекс ID, GitHub или ключом доступа (passkey) — и нажмите «Разрешить» на странице «Вход в FormaCAD на компьютере». Пароль в приложении не вводится.
3. Браузер вернёт приложению одноразовый код; в окне аккаунта появятся имя, тариф, состояние прав и срок их офлайн-действия.
4. «Проверить снова» обновляет права онлайн. «Выйти» отзывает вход на сервере и удаляет локальные учётные данные. «Открыть кабинет» открывает сайт.

Ожидание подтверждения можно отменить; через 5 минут оно завершается само.

## Технический маршрут

- OAuth 2.0 Authorization Code + PKCE (S256) для нативного публичного клиента без секрета (RFC 8252). Для каждой попытки создаются новые `code_verifier`, `state` и `nonce`.
- Приложение открывает `https://cad.kartochk1n.ru/oauth/authorize` в системном браузере и слушает одноразовый адрес `http://127.0.0.1:<случайный порт>/callback`. Обратный вызов с чужим `state` игнорируется; параметр `iss` должен совпасть с сервером (RFC 9207).
- В адресной строке передаётся только короткоживущий одноразовый код. Обмен кода и все токены остаются в Rust-части приложения; WebView получает только профиль и права.
- Access token живёт около 10 минут и хранится только в памяти. Refresh token ротируется при каждом обновлении и хранится в защищённом хранилище ОС (Windows Credential Manager, macOS Keychain, Linux kernel keyring). Повторное использование старого refresh token сервер расценивает как кражу и отзывает весь вход.
- Права приходят подписанным документом (EdDSA/Ed25519, `typ: forma-entitlement+jwt`). Приложение проверяет подпись по опубликованным ключам `/api/v1/entitlements/keys`, издателя, аудиторию, версию и срок.

Код: [account](../../apps/desktop/src-tauri/src/account/), [интерфейс](../../apps/desktop/src/features/account/).

## Хранение данных

| Что | Где |
| --- | --- |
| Refresh token | Хранилище учётных данных ОС, сервис `studio.forma.cad.account` |
| Access token | Только память процесса |
| Профиль, подписанный документ прав, публичные ключи, время последней проверки | Таблица `settings` (ключ `account_cache`) локальной SQLite |

Проекты и модели на сервер не отправляются.

## Офлайн и отзыв

Документ прав действует ограниченный срок (по умолчанию 7 дней) и рекомендует онлайн-проверку через 24 часа. Без сети приложение использует сохранённый документ до его срока. Отзыв (возврат платежа, отключение устройства в кабинете, выход) вступает в силу при следующей онлайн-проверке или по истечении срока — бессрочного офлайна нет. Если часы компьютера переведены назад относительно уже виденного времени, права считаются неподтверждёнными. Полной защиты от владельца полностью контролируемого компьютера это не даёт.

Сейчас в приложении нет локальных платных функций: права отображаются, но бесплатное ядро от них не зависит.

## Ограничения

- Сервер по умолчанию — `https://cad.kartochk1n.ru`. Для разработки задайте `FORMA_ACCOUNT_SERVER=http://127.0.0.1:5173` (http разрешён только для 127.0.0.1).
- Способы входа определяет сайт, а не приложение: новые способы появляются без обновления CAD. Вход через VK ID проверен на развёрнутом сервере; вход из приложения локально проверялся с заменой VK ID и тестовым паролем.
- На Linux kernel keyring не переживает перезагрузку: после неё нужен повторный вход.

## Проверка

- Rust: `cargo test --lib account` — PKCE (вектор RFC 7636), loopback, проверка подписи (подделка, чужой ключ, ротация, истечение, перевод часов), недоступный сервер.
- Сквозной тест против запущенного сервера: `FORMA_ACCOUNT_E2E_SERVER=… FORMA_ACCOUNT_E2E_EMAIL=… FORMA_ACCOUNT_E2E_PASSWORD=… cargo test --lib account -- --include-ignored`.
- Интерфейс: `npm test -- src/features/account`.
