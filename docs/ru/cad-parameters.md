# Именованные параметры и размеры

[Документация](index.md) · [English](../en/cad-parameters.md) · [Связи](sketch-constraints.md)

В дереве типизированной модели откройте «Именованные параметры CAD». Введите название и значение в миллиметрах, нажмите «Добавить параметр». Название остаётся пользовательским текстом; новый уникальный ID parameter_N сохраняется независимо от значения. Существующие параметры отображаются сразу. Меняйте значение в строке: все операции, ссылающиеся на этот ID, будут пересчитаны при построении.

Добавьте связь длины на обычном или вспомогательном ребре. В «Источник размера» выберите параметр вместо числового значения. Связь хранит `{kind: "parameter", parameterId: ...}`; числовое поле скрывается, отображается текущее значение параметра. При возврате к «Числовой размер» копируется текущее значение (с нижней границей 0,01 мм). Фиксация координат пока не привязывается к параметру.

Строка параметра показывает ID использующих его операций. Пока есть ссылки, удаление запрещено: сначала отвяжите размеры. Поиск охватывает все поля операций, включая выключенные операции. Удалять неиспользуемый параметр разрешено. Не более 10 000 параметров; конечные значения по модулю до 10 000 мм; название непустое, до 120 символов, без управляющих символов. Отрицательное значение допустимо для некоторых операций, но длина эскиза должна оставаться положительной: ошибку покажет solver.

[Редактор](../../apps/desktop/src/components/CadParameterEditor.tsx) меняет `document.parameters` в том же черновике, что и дерево. [Поиск ссылок](../../apps/desktop/src/lib/cadParameters.ts) не изменяет операции. Новая ревизия сохраняется после успешного построения; ни ввод параметра, ни диагностика не перезаписывают сохранённую модель. Старые документы и SQL остаются совместимыми. [Тесты](../../apps/desktop/src/lib/cadParameters.test.ts) проверяют ID, границы и ссылки. Предпросмотр сейчас относится только к 2D-эскизу; автоматического 3D-предпросмотра всей модели нет.


В 1.2.6 параметры могут управлять координатами нескольких эскизов и их началами. Откройте «Редактировать 2D-эскиз» → «Связи координат с параметрами»; правила, сохранение и пример связанных профилей описаны в [руководстве эскизов](sketches.md#явные-связи-координат). Проверка перед построением предлагает явный выбор, если геометрические ограничения меняют нарисованную форму.
