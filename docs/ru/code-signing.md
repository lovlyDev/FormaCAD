## Лицензия

FormaCAD распространяется по лицензии **GNU GPL версии 3 или более поздней** (`GPL-3.0-or-later`), полный текст — в [LICENSE](../../LICENSE). Код можно изучать, изменять и распространять; изменённые версии тоже должны выходить под GPL с исходным кодом.

Сторонние компоненты сохраняют свои лицензии: OpenCascade (LGPL-2.1 с исключением OCCT, лицензии лежат рядом с пакетом), `vendor/tauri-plugin-updater` (MIT/Apache-2.0), зависимости npm и Cargo (MIT, Apache-2.0, BSD, ISC и совместимые). Владелец проекта и решение о лицензии — lovlyDev.

## Политика подписи кода

Установщики Windows планируется подписывать бесплатным сертификатом SignPath Foundation через SignPath.io. Пока подпись не подключена, Windows может показывать «Неизвестный издатель».

После подключения:

- Подписывается только собственная программа FormaCAD, собранная из исходников этого репозитория в GitHub Actions (Release workflow). Сторонние библиотеки (OpenCascade и другие) не подписываются сертификатом проекта.
- Каждый выпуск подписывается только после ручного одобрения.
- Строка благодарности: *Free code signing provided by [SignPath.io](https://signpath.io), certificate by [SignPath Foundation](https://signpath.org).*

### Приватность

Программа работает локально; проекты, модели и настройки не отправляются на серверы FormaCAD. Сетевые запросы:

- проверка обновлений на GitHub (стабильный канал) или на formacad.ru (бета-канал, только после входа в аккаунт);
- необязательный вход в аккаунт FormaCAD и обновление прав аккаунта на formacad.ru;
- каталог плагинов plugins.formacad.ru при его открытии;
- запросы ИИ к выбранному пользователем CLI-провайдеру, только когда пользователь разрешил действие.

Подробнее: [данные](data.md), [безопасность](../../SECURITY.md) и политика конфиденциальности на [formacad.ru](https://formacad.ru). Программа не меняет системные настройки без предупреждения и удаляется штатно: «Параметры Windows → Приложения» или деинсталлятор в папке установки.
