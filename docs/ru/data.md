# Данные и восстановление
[Документация](index.md) · [English](../en/data.md)

Идентификатор studio.forma.cad не меняется между релизами. Установщик заменяет программу, а не каталог данных.

| Система | Каталог по умолчанию |
| --- | --- |
| Windows | %APPDATA%/studio.forma.cad |
| macOS | ~/Library/Application Support/studio.forma.cad |
| Linux | $XDG_DATA_HOME/studio.forma.cad, обычно ~/.local/share/studio.forma.cad |

FORMA_DATA_DIR позволяет выбрать абсолютный путь к отдельному тестовому каталогу.

- forma.sqlite хранит проекты, ревизии, разрешения, события восстановления и настройки интерфейса.
- projects/ содержит модели, вложения и JSON для восстановления.
- cad-python.txt хранит путь к выбранному интерпретатору.
- WebView хранит состояние UI; копия настроек также записывается в SQLite и восстанавливает отсутствующие значения при запуске.
- Плагин window-state сохраняет положение, размер и развёрнутое состояние окна.
- backups/ содержит отдельные снимки SQLite перед обновлениями из приложения. Они не удаляются автоматически.

Сохраняются последний проект, положение/ориентация/центр/масштаб камеры, проекция, режим отображения, сетка, видимость и выбор тел, размеры панелей, папки дерева, сравнение, черновики редактора/чата и состояние движения. Видимость тела привязана к имени и позиции в модели, а не временному UUID Three.js. Изменение топологии может сделать старое выделение неприменимым; это ещё не постоянное именование топологии.

Незавершённые AI-операции, разовые разрешения и открытые подтверждения после перезапуска не выполняются заново. Готовые данные сохраняются; прерванные задачи отмечаются для восстановления. Копия SQLite содержит метаданные и настройки, а модели остаются в projects/. Для полного внешнего бэкапа скопируйте весь каталог при закрытой Forma.

## Восстановление
Закройте Forma и скопируйте весь каталог данных в безопасное место. Выберите нужный снимок из backups/. Сохраните текущие forma.sqlite и возможные -wal/-shm отдельно, затем замените базу выбранным снимком при закрытом приложении. Сохраните каталог projects/ рядом. Не копируйте базу поверх открытой.

Не выбирайте удаление данных приложения при обновлении. Запускайте обычный установщик поверх существующей установки. Для переноса на другой компьютер отдельно скопируйте данные и укажите действующий локальный путь Python.
