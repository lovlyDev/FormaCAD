# Смещение профиля

[Документация](index.md) · [English](../en/offset-profile.md) · [M4](modeling-ii.md)

Команда изменяет плоский профиль авторского вытягивания точным OCCT-смещением. Исходный профиль и вытягивание остаются в истории; новое вытягивание сохраняет исходное выражение длины, включая ссылку на параметр.

## Действия пользователя

Откройте модель с доступным авторским вытягиванием. В меню «Инструменты» выберите «Сместить профиль». Выберите тело по имени и полному ID; при нескольких телах без выделения автоматического выбора нет. Диалог показывает исходный профиль и его полный ID. Укажите ненулевое смещение в миллиметрах и соединение углов: пересечение продолженных рёбер либо скругление внешних углов. Положительное смещение расширяет материал, отрицательное сужает. Поле принимает дробные значения.

Проверьте настоящий 3D-предпросмотр и измерения. «Построить» доступно только после успешной проверки геометрии. Подтвердите разрешение. «Отмена» не меняет проект. Undo/redo выполняются явными кнопками истории; созданная ревизия остаётся в истории.

## Ядро, команды и данные

Маршрут: features/offset-profile → apply_ir_commands → staged-копия с expectedRevision → CAD IR OffsetProfile → native/offset_profile → cad-core/src/offset_profile.cpp → OCCT. Новый PlanarProfile хранит плоскую BREP-область с проверенными конечными положительными площадью и периметром. Контракт Solid с обязательным положительным объёмом не менялся.

CAD IR хранит sketchId, signed Dimension offset и явный join (intersection/rounded). Поддержаны прямоугольник, окружность, решённый sketch2d с отверстиями и ранее смещённый профиль. Параметры и все зависимости сохраняются при перестроении и независимом копировании тела. Плоский профиль может использоваться API вытягивания и вращения.

Наружный контур смещается на d, каждый внутренний — на −d. Проверяются замкнутость, BREP, вложенность отверстий, их пересечения и сохранение числа контуров. Исчезновение отверстия, схлопывание, разделение на несколько областей и выход отверстия наружу явно отклоняются. Источник копируется до OCCT-вычислений. Углы окружностей остаются точными дугами, без полигональной аппроксимации.

Пакет add_feature(OffsetProfile) + add_feature(Extrude) + set_body_source создаёт одну ревизию только после успешного worker. Семантика прежних features сохраняется, ссылок вперёд нет. Общий Command API может явно сериализовать ранее пропущенные значения по умолчанию, например construction: false; program уже сохранённой старой ревизии не переписывается. При ошибке откатываются метаданные, артефакты и история. Схема хранения и SQL-миграции не менялись.

## Проверка

C++ проверяет BREP и STEP round-trip положительного и отрицательного вытягивания в XY/XZ/YZ со смещённым началом, окружности, скруглённые углы, отверстия и вращение. Прямоугольник 40×20, смещение +2, H10: 10560 мм³ / 3472 мм²; −2: 5760 мм³ / 2192 мм². Профиль 40×20 с отверстием 10×6: +2 даёт 10440 мм³ / 3608 мм², −2 — 4360 мм³ / 2392 мм². Окружность R10, +2, H10: 1440π мм³ / 528π мм². Скруглённый прямоугольник +2: 10400+40π мм³ / 3280+48π мм².

В собранном Windows-приложении со встроенным production frontend выполнена цепочка UI → настоящий IPC → host → OCCT: RU/EN × dark/light — 4/4 PASS, без JavaScript-ошибок. Проверены настоящие холсты, ошибки нулевого/пустого смещения, схлопывания и исчезновения отверстия, отмена без ревизии, одна успешная ревизия, сохранение выражения длины и program старой ревизии, undo/redo с сохранением истории.

Локально прошли 28 CTest, 281 Rust lib (2 штатных ignored), настоящий worker transaction с полным откатом и STEP, 309 Vitest, fmt, строгий Clippy default/native-occt, lint/build и проверки каталогов/документации. Полный browser e2e дал 71 PASS / 89 штатных skip; исходный сценарий карточек дополнительно прошёл 3/3 после исправления навигации. Полная CI-матрица OCCT по ОС не запускалась. Воспроизводимый сценарий: [offset-profile-native.mjs](../../scripts/acceptance/offset-profile-native.mjs). Используйте отдельный профиль собранного native-worker-client приложения со встроенным frontend (без devUrl), настоящий OCCT worker и loopback CDP http://127.0.0.1:9336. Установите FORMA_NATIVE_ACCEPTANCE=isolated и запустите `node scripts/acceptance/offset-profile-native.mjs http://127.0.0.1:9336 <абсолютный-путь-к-report.json>`. Создаются только тестовые проекты отдельного профиля; JSON/PNG записываются рядом с отчётом. Fixture ждёт публикации видимой миниатюры; это не проверка немедленного read-after-write и не исправление Issue #32. Неудачные IPC не повторяются.

## Ограничения

UI работает с телом, активный источник которого — авторское вытягивание поддержанного профиля. Булевы результаты, импортированные тела и произвольные CAD-грани не выбираются неявно вместо профиля. API поддерживает вращение, но отдельного UI его создания в этом диалоге нет. Нет автоматической перепривязки новых граней или отдельного F9-редактора OffsetProfile. Число контуров сохраняется: даже математически допустимое исчезновение отверстия требует другого явно спроектированного изменения эскиза. Для исходного многоугольного профиля действует предел 32 точки и 7 отверстий. Диапазон смещения — ±10000 мм, модуль больше 1e−7 мм. Операция не подавляется отдельно как модификатор солида; используйте явную историю. Код и ресурсы Blender не использовались.
