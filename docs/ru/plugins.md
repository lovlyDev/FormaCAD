# Плагины

[Документация](index.md) · [English](../en/plugins.md) · [Спецификация платформы](plugin-platform.md) · [Руководство автора](plugin-authoring.md)

Плагины добавляют в FormaCAD новые параметрические операции, команды, форматы импорта и экспорта, панели и настройки. Плагин — WebAssembly-компонент, который работает в песочнице Wasmtime внутри CAD. Он не видит файлы, сеть и программы компьютера: всё, что он может, — вызвать функции FormaCAD, на которые вы дали права.

## Установка

**Из файла.** Настройки → «Плагины» → «Установить из файла…» → выберите `.cadplugin`. FormaCAD проверит пакет и откроет окно установки. Так ставятся плагины, которых нет в каталоге, и сборки авторов во время разработки. Каталог и сеть для этого не нужны.

**Из каталога.** Кнопка «Добавить в FormaCAD» на `plugins.formacad.ru` открывает ссылку `formacad://plugins/install?id=…&version=…`. FormaCAD скачивает подписанную запись каталога и сам пакет только с `plugins.formacad.ru`, проверяет подпись и SHA-256 и показывает то же окно установки. Ключ каталога встроен в приложение начиная с версии 1.4.0; если сборка его не содержит, установка по ссылке отвечает «В этой сборке нет ключа каталога» — тогда используйте файл. Опубликовать свой плагин в каталоге — см. [руководство автора](plugin-authoring.md#релиз-для-каталога).

**Окно установки** показывает название, автора, версию, источник, контрольную сумму и права простыми словами. Ничего не устанавливается, пока вы не нажмёте «Установить». Ссылка `formacad://` сама по себе никогда ничего не выполняет.

## Права

| Право | Что разрешает |
| --- | --- |
| `model.read` | Читать текущую модель: параметры, операции, тела |
| `model.write` | Предлагать изменения модели; они применяются одной ревизией, которую можно отменить |
| `selection.read` | Видеть, какие тела, грани или рёбра вы выбрали |
| `file.import` | Читать файл, который вы выберете в окне импорта |
| `file.export` | Записывать данные в файл, который вы выберете в окне сохранения |
| `storage` | Хранить свои данные в профиле FormaCAD (до 10 МБ) |
| `network:<хост>` | Отправлять HTTPS-запросы только на указанный хост |
| `notifications` | Показывать уведомления |

Пакет, который вызывает функцию без объявленного права или пытается обратиться к системе в обход FormaCAD (например, WASI), не устанавливается.

## Обновление и версии

При установке новой версии окно показывает установленную версию и отмечает **новые** права пометкой «Новое». Пока вы не согласились, остаётся прежняя версия. Версии хранятся рядом (`plugins/<id>/<версия>/` в профиле); если их несколько, в карточке плагина можно выбрать активную. Переключиться на версию с новыми правами из настроек нельзя — установите её заново, чтобы увидеть окно согласия. Одна и та же версия с другим содержимым отклоняется.

## Использование

Действия включённых плагинов появляются в палитре команд (`Ctrl K`): «<плагин>: <операция>», «…: импорт …», «…: экспорт …», «…: панель …». Операция открывает форму параметров (длины в мм, углы в градусах), затем обычное подтверждение изменения модели. FormaCAD проверяет результат плагина (CAD IR v2, ID, построение BREP) и сохраняет **одну** ревизию; при любой ошибке модель не меняется. В истории изменение подписано «Плагин <имя> <версия>: <операция>».

Результат операции — обычные операции CAD. Тело остаётся видимым, измеряется и экспортируется даже после выключения или удаления плагина.

Импорт плагином открывает системное окно выбора файла; плагин получает только байты выбранного файла. Экспорт отдаёт плагину текущую модель и записывает результат туда, куда вы укажете.

## Настройки, журнал, удаление

Карточка плагина в «Настройки → Плагины»: версия, автор, переключатель «Включён», права, настройки плагина (если он их объявил), журнал вызовов и удаление. Журнал хранится локально в `plugins/journal.jsonl` профиля и никуда не отправляется. «Удалить» убирает все версии плагина и его данные (`plugins/data/<id>`), после второго подтверждения.

## Ограничения и ошибки

- Вызов плагина ограничен топливом вычислений, памятью 256 МБ и временем 10 с. Превышение останавливает только этот вызов: FormaCAD продолжает работу и сообщает, что ошибка в плагине.
- Ошибка плагина показывается с его ID и кодом, отдельно от ошибок CAD.
- Повторно открыть операцию плагина с прежними параметрами пока нельзя: изменяйте её как обычные операции или выполните плагин снова.
- Панели плагинов открываются окном из палитры, а не в боковой колонке.
- Если CAD уже запущен, ссылка `formacad://` на Windows открывает второе окно с окном установки.
- Плагины работают только в настольном приложении.

## Проверка

`cargo test --lib plugins::` (пакет, манифест, права, лимиты, сквозная установка примера), `cargo test --features native-occt --test plugin_gear` (пример строит геометрию OCCT), `npx vitest run src/features/plugins` (окно установки и формы), `npm run check:i18n`, `npm run check:docs`.
