# Настройки, локализация и обновления

[Документация](index.md) · [English](../en/settings-and-updates.md) · [Данные](data.md) · [Релизы](releases.md)

Панель настроек разделена на AI-агентов, CAD-окружение, разрешения, оформление и приватность. Список окружения показывает, найден ли нужный инструмент, и обновляется кнопкой повторной проверки. Провайдер AI выбирается для текущего проекта; параметры Custom CLI и подтверждений хранятся локально. Выбор Python/CadQuery нужен для старых документов, а встроенное нативное ядро строит CAD IR v2. Кнопка выбора интерпретатора открывает системный диалог и проверяет окружение. Подробнее о провайдерах и полном журнале решений — [AI и разрешения](ai.md); реализация настроек: [SettingsDialog.tsx](../../apps/desktop/src/app/dialogs/SettingsDialog.tsx).

## Язык и тема

Русский — язык по умолчанию; английский переключается в «Оформлении». Выбор сразу меняет интерфейс и сохраняется для следующего запуска. `ru.json` и `en.json` содержат одинаковый набор пользовательских ключей; локальные строки ошибок переводятся перед показом, а пользовательский текст, код и имена файлов остаются исходными. Числа, даты и формы множественного числа форматируются выбранной локалью. [Модуль i18n](../../apps/desktop/src/i18n/index.ts), [каталоги](../../apps/desktop/src/i18n/).

Светлая и тёмная темы меняют поверхности, текст, границы и WebGL-сцену без сброса модели. Выбранная тема сохраняется. Фиолетовый акцент используется в обеих темах. Если окно браузера очищает свои данные, настольное приложение восстанавливает отсутствующие сохранённые предпочтения из SQLite. Это не означает, что любое несохранённое действие восстанавливается: ожидающие AI-задачи и одноразовые подтверждения после перезапуска не продолжаются. См. [theme.ts](../../apps/desktop/src/lib/theme.ts), [persistence.ts](../../apps/desktop/src/lib/persistence.ts), [данные](data.md).

## Проверка и установка версии

Настольное приложение проверяет наличие обновления вскоре после запуска и затем раз в шесть часов; кнопка обновлений позволяет проверить вручную. Если найдена новая опубликованная версия, открывается окно с номером, Markdown-описанием изменений и действиями «Установить» и «Позже». Ссылки из заметок открываются через системный браузер, неизвестные схемы ссылок отбрасываются. При активном редакторе или операции предложение ждёт завершения. «Позже» закрывает окно; доступное обновление остаётся у кнопки. Нет сети или релиза — запуск приложения продолжается. Код: [Updates.tsx](../../apps/desktop/src/components/Updates.tsx).

Во время скачивания видна полоса с процентами, если сервер сообщает размер; иначе показывается неопределённый прогресс. Перед установкой Forma сохраняет предпочтения, ждёт завершения текущих операций и создаёт снимок SQLite через `VACUUM INTO`, включая подтверждённые записи WAL. Затем пакет проверяется механизмом подписи Tauri updater и устанавливается. Каталог данных и идентификатор приложения не меняются. При обычном обновлении проекты, ревизии, расположение камеры, видимость тел, черновики, темы и язык должны остаться. [Backend обновления](../../apps/desktop/src-tauri/src/updates.rs), [резервное копирование](data.md).

Windows использует встроенный установщик, macOS и Linux AppImage поддерживают путь самoобновления. Для Linux DEB/RPM вместо него установите более новый пакет менеджером пакетов; данные останутся в каталоге приложения. Проверка публикации через GitHub видит только **опубликованные** версии: локальная 1.2.6 не предлагается пользователям 1.2.5. Платформенная подпись macOS/Windows и подпись updater — разные вещи; условия сборки описаны в [релизах](releases.md), статус проверки — в [статусе](status.md).
## Бета-канал для сторонников

Активные сторонники FormaCAD (см. программу поддержки на formacad.ru) могут получать бета-версии раньше стабильных. После входа в аккаунт в окне «Обновления» появляется «Канал обновлений»: «Стабильный» или «Бета (для сторонников)». Выбор сохраняется. Без права `beta.access` в документе аккаунта (не вошли, статус закончился) выбора нет и используется стабильный канал.

- **Маршрут.** Стабильный канал — подписанный `latest.json` открытого релиза GitHub из `tauri.conf.json`. Бета-канал проверяет команда Rust `beta_update_check` (`apps/desktop/src-tauri/src/beta_update.rs`): она берёт токен доступа аккаунта (`account::commands::access_token`, токен не попадает в WebView), запрашивает `/api/v1/desktop/beta/latest.json` на сервере аккаунта с заголовком `Authorization` и возвращает тот же объект обновления, что и `check()`. Заголовок сохраняется в объекте, поэтому скачивание установщика тоже идёт через сервер с этим токеном.
- **Проверка прав.** Сервер при каждом запросе заново проверяет статус сторонника; файлы лежат в приватном репозитории `lovlyDev/FormaCAD-beta`. Подпись обновления проверяется тем же ключом, что и у стабильных версий.
- **Версии.** Беты нумеруются `x.y.z-beta.N`. С беты 1.7.0-beta.1 приложение перейдёт на стабильную 1.7.0, когда она выйдет. С беты на более старую стабильную версию оно не откатывается.
- **Код.** `components/updates/updateChannel.ts` (выбор канала, тест `updateChannel.test.ts`), `components/Updates.tsx`, строки `updates.channel*`.
